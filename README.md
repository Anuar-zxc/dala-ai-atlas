# Dala Atlas

Интерактивная карта ИИ-компаний казахстанской экосистемы и проектов nFactorial Incubator. Интерфейс и каталог находятся в `public`. Заявки принимает функция Vercel в `api/submissions.js`.

## Источники и география

Каталог опирается на публичную витрину nFactorial с выпусками 2022–2026 годов, профили Startup Radar, отборы Digital Qazaqstan Battle и Startup Orda, сайты региональных вузов и публикации команд. Описание в карточке передаёт назначение продукта по источникам. Состав команды и стадия могут быть доступны на дату публикации источника. Для архивного проекта выпуск обозначает участие в программе.

- `city` — город, связанный с компанией, командой или автором согласно источнику в карточке.
- `alsoCities` — дополнительные города с подтверждённой командой, разработкой или внедрением. Одна карточка может открываться из нескольких городов.
- `programCity` — место проведения инкубатора для архивного проекта. При пустом `city` такой проект входит в отметку города программы.
- `aliases` — дополнительные варианты названия для поиска.
- `batch` — год выпуска nFactorial. У компаний без указанного выпуска это поле отсутствует.
- `kind` — `incubator` для проекта из витрины, `company` для остальных команд.

Если оба поля города пусты, проект появляется в группе «Без города». Режим «Все проекты» показывает отдельную отметку для каждой карточки. Для новых городов добавьте долготу и широту в `locations` в `public/app.js`. Контуры стран на карте получены из Natural Earth, масштаб 1:50m, public domain.

## Редактирование и модерация

Форма записывает заявки в папку `pending` закрытого хранилища Vercel Blob `dala-ai-atlas-submissions`. Повторная отправка одинаковой заявки использует тот же ключ. Редактор открывает заявку в панели редакции и проверяет, как продукт использует ИИ, связь с Казахстаном и состав команды.

Для массовых обновлений можно добавить записи в `public/startups.json` по образцу соседних. Укажите уникальный ID, публичные ссылки на источники и дату сверки. Роль автора указывайте так, как её описывает источник. Храните логотипы в `public/logos`. При отсутствии логотипа поставьте `null`, и интерфейс покажет монограмму. После проверки изменения публикуются через GitHub и Vercel.

## Запуск

Выполните `npm ci` и `npm run check`, чтобы проверить данные. Для просмотра запустите `python3 -m http.server 8000 --directory public`. Для запуска с API используйте `vercel dev` с подключённым приватным Blob store.

## Панель редакции

Панель доступна на `/admin.html`. Пароль хранится как секрет `DALA_ADMIN_PASSWORD` в продакшен-окружении Vercel. Редактор может опубликовать или отклонить заявку, вернуть её на проверку, создать карточку вручную и отредактировать или скрыть опубликованную карточку.

Исходный каталог остаётся в Git. Правки редакции хранятся в одном закрытом документе `editorial/catalog-v1.json` и применяются поверх исходных записей по ID. Публичный API отдаёт только опубликованные правки и ID скрытых карточек. Заявки и статусы проверки доступны редактору после входа. Условная запись по ETag защищает правки от перезаписи при параллельном редактировании.

Поле `stageKey` определяет фильтр по стадии. Поле `stage` передаёт публичный статус. Публичные контакты можно добавить в поле редактора, указав имя или назначение и ссылку в формате `Название | https://…`. Для рабочей почты используйте `mailto:`. Карточки, оформленные через редакцию, появляются в каталоге и на карте после обновления кэша API, без нового деплоя.
