# Dala Atlas

Интерактивная карта ИИ-компаний казахстанской экосистемы и проектов nFactorial Incubator. Интерфейс и каталог находятся в `public`. Заявки принимает функция Vercel в `api/submissions.js`.

## Источники и география

Каталог опирается на публичную витрину nFactorial с выпусками 2022–2026 годов, профили Startup Radar и публикации команд. Описание в карточке передаёт назначение продукта по источникам. Состав команды и стадия могут быть доступны на дату публикации источника. Для архивного проекта выпуск обозначает участие в программе.

- `city` — город, связанный с компанией, командой или автором согласно источнику в карточке.
- `programCity` — место проведения инкубатора для архивного проекта. Используется на карте, если `city` пуст.
- `batch` — год выпуска nFactorial. У компаний без указанного выпуска это поле отсутствует.
- `kind` — `incubator` для проекта из витрины, `company` для остальных команд.

Если оба поля города пусты, проект появляется в группе «Без города». Для новых городов добавьте долготу и широту в `locations` в `public/app.js`. Контуры стран на карте получены из Natural Earth, масштаб 1:50m, public domain.

## Редактирование и модерация

Форма записывает заявки в папку `pending` закрытого хранилища Vercel Blob `dala-ai-atlas-submissions`. Повторная отправка одинаковой заявки использует тот же ключ. Редактор открывает заявку в панели Storage и проверяет, как продукт использует ИИ, связь с Казахстаном и состав команды.

Для публикации добавьте запись в `public/startups.json` по образцу соседней. Укажите уникальный ID, публичные ссылки на источники и дату сверки. Роль автора указывайте так, как её описывает источник. Храните логотипы в `public/logos`. При отсутствии логотипа поставьте `null`, и интерфейс покажет монограмму. После проверки изменения публикуются через GitHub и Vercel.

## Запуск

Выполните `npm ci` и `npm run check`, чтобы проверить данные. Для просмотра запустите `python3 -m http.server 8000 --directory public`. Для запуска с API используйте `vercel dev` с подключённым приватным Blob store.
