# Dala Atlas

Публичный каталог ИИ-команд, связанных с Казахстаном. Статический интерфейс находится в public, заявки принимает функция Vercel в api/submissions.js.

## Редактирование и модерация

Форма записывает каждую заявку в закрытый Vercel Blob store dala-ai-atlas-submissions в папку pending. Одинаковые заявки используют одинаковый ключ. Редактор открывает заявку в панели Storage, проверяет ссылку на продукт, роль ИИ, связь с Казахстаном и состав команды. Для публикации добавьте запись в public/startups.json по образцу соседней. Используйте стабильный уникальный id, публичные ссылки на подтверждения и дату проверки. Указывайте роль автора так, как она подтверждена источником. Если город неизвестен, оставьте city пустым. Логотипы лежат в public/logos. Новые сферы и города появляются в фильтрах автоматически. Координаты для нового города добавьте в locations в public/app.js (проекция карты: x = 33 + (долгота − 46) × 14, y = 35 + (56 − широта) × 21).

## Запуск

npm ci и npm run check проверяют набор данных. Для просмотра запустите python3 -m http.server 8000 --directory public. Для полной среды с API используйте vercel dev с подключённым приватным Blob store. Публикация через vercel --prod. Границы карты получены из Natural Earth 1:50m, public domain.
